# MSR VPN: downloads

A private VPN for invited people. **Download page: https://msr-almandhari.github.io/msr-vpn-app/**

- **Mac:** [MSR VPN for Mac](https://github.com/MSR-Almandhari/msr-vpn-app/releases/latest/download/MSR-VPN-mac.zip) (macOS 13+, Apple Silicon and Intel)
- **Windows, iPhone, Android:** the official [WireGuard](https://www.wireguard.com/install/) app for now

You need a personal setup from the admin. Each setup works on one device only.

## Open-source parts

MSR VPN for Mac bundles, unchanged:
- [wireguard-go](https://git.zx2c4.com/wireguard-go) (MIT)
- [wireguard-tools](https://git.zx2c4.com/wireguard-tools): `wg`, `wg-quick` (GPL-2.0)
- [GNU bash](https://www.gnu.org/software/bash/) 5.2 (GPL-3.0)

Their source code, at the exact versions used, is attached to each release as `MSR-VPN-mac-open-source-parts.tar.gz`.
